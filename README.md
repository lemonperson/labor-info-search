# 劳动信息检索

一款免费的 Windows 桌面工具，帮助你在购买前查找企业劳动权益相关的公开信息。它整理来源和上下文，供你自行核验；**不是黑名单，也不是法律意见，不给企业打分，也不替你决定是否购买。**

## 下载与安装

在本仓库的 **Releases** 页面选择最新版本：

- `劳动信息检索-<版本>-x64.exe` 是安装程序。双击后按提示安装到当前 Windows 用户账户，不需要管理员权限。
- `劳动信息检索-<版本>-x64-portable.exe` 是免安装版。下载后放在你自己的文件夹中，双击运行；不要直接从压缩包预览窗口启动。
- `*.sha256` 文件用于核对下载文件是否完整。PowerShell 可运行 `Get-FileHash .\文件名.exe -Algorithm SHA256`，并将结果与发布页公布的校验值比较。

本应用目前没有代码签名证书。Windows SmartScreen 可能显示“Windows 已保护你的电脑”或“未知发布者”。只有在你确认下载地址属于本项目的 Releases、并核对 SHA-256 一致后，才继续：选择“更多信息”，再选择“仍要运行”。如果下载来源或校验值不一致，请删除文件，不要运行。应用不会自动更新；请从 Releases 手动下载新版。

## 开始使用

1. 双击启动应用，阅读首次使用说明并选择是否保存本机历史。
2. 输入企业/品牌名称，或粘贴淘宝、京东、抖音、拼多多商品链接，或选择 PNG、JPG/JPEG、WebP 截图（最大 20 MiB）。OCR 在本机运行。
3. 检查品牌方、店铺经营者、生产商等候选主体，修正后确认。只有确认后才开始公开来源检索。
4. 阅读结果、日期、来源性质和原文链接。需要在浏览器继续搜索时，应用会先显示具体查询并要求你确认。

联网检索使用 Bing 公开 RSS 搜索服务，覆盖不完整。截图 OCR、设置和历史可离线使用。无账号、API 密钥或 Python/Node.js 运行环境要求。

## 结果边界和已知限制

- 搜索只涵盖当前公开检索可访问的来源；结果可能遗漏、过期、重复或与目标主体同名。没有结果不代表没有相关事件。
- 商品页面可能因登录、验证码、页面动态加载、地区限制或平台改版而无法读取。此时可尝试手动输入或截图。
- 首版聚焦中国大陆企业及中文信息。不同品牌方、销售方、生产商、委托方和代工厂不可自动视为同一主体；应用不提供权威工商核验。
- 搜索结果中的指控不等于已经证实。请查看原文、上下文、企业回应、裁判/监管信息和后续更正。应用不提供法律意见、企业劳动表现评分、排行榜或购买建议。

## 隐私

没有账号、遥测或广告追踪。检索历史和设置保存在本机 Windows 用户数据目录，可在应用中关闭历史保存、删除单条或清空历史。卸载不会自动删除这些数据。开始检索时，查询词会发送给 Bing；解析商品链接时，应用会请求你粘贴的公开商品页。截图不会上传，应用不保存原图或其路径。详见 [隐私说明](PRIVACY.md)。

## 开发者：从源码构建

普通使用者不需要本节中的开发工具。开发需要 Windows 10/11 x64、Node.js 24、pnpm 11.25.0 和 Git：

```powershell
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

验证及生成 Windows 发布文件：

```powershell
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm dist:win
pnpm dist:portable
pnpm playwright test tests/e2e/packaged-app.spec.ts
```

架构和信任边界见 [docs/architecture.md](docs/architecture.md)，贡献指南见 [CONTRIBUTING.md](CONTRIBUTING.md)。
